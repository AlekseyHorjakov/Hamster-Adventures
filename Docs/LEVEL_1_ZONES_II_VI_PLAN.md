## 0. Вводная

По карте уровня осталось три официальных зоны: II «Озеро» (06-10), III «Густой лес» (11-16),
IV «Финал» (17-18) - 13 комнат. Чтобы работать теми же короткими блоками, что и Зона I,
оставшееся разбито на **5 этапов по 2-3 комнаты**. Каждый этап заканчивается приёмкой:
guard-проверка, PlayMode-тесты, сборка, кадры из exe, стоп и согласование.

Правила эталона (`Docs/LEVEL_1_ZONE1_REFERENCE.md`) действуют без изменений:
трава = `groundTop`, декор по рейкасту до земли, платформы one-way с настилом на уровне
коллайдера, ямы с дном/стенками либо без дна (респавн), камера не ниже `surfaceY + 2`,
движение/бой/камеру не переписываем.

## 4. Definition of Done для каждого этапа

1. Комнаты собраны в `Level01_Full.unity`, маршрут проходим соло и в кооперативе.
2. Все поверхности/платформы/ямы совпадают с `LEVEL_1_GEOMETRY.md`, декор не висит в воздухе.
3. `ZoneNReferenceGuard` = PASS, PlayMode-тесты этапа зелёные.
4. Windows-билд пересобран, кадры из запущенного exe (не редактора) приложены.
5. Короткий отчёт + стоп до согласования.

## 5. Риски

- **Вода**: визуал воды легко расходится с коллайдерами - коллайдеры только по земле/камням,
  вода не имеет физики, кроме «неглубоких» зон без урона.
- **Водопад**: вертикальная камера и длинный подъём - сначала собрать подъём, потом декор.
- **Кооп**: гейты боёв должны открываться только когда мертвы все гиены и оба игрока живы/возрождены.
- **Сейвы**: смена формата чекпоинтов - миграция v1/v2 обязательна.
- **Арт**: не хватает воды/водопада/ловушек - этапы 2 и 4 начинать с проверки ассетов,
  при нехватке - временные плейсхолдеры из имеющихся слайсов.
