## Нарезка
`Assets/Art/Level01/WaterSlices/` - 139 корректных слайсов (connected components, без обрезков):
- `Stone_01-26` - камни и дорожки (25/26 - широкие цепочки).
- `Shore_01-06` - длинные берега, `Shore_07-14` - торцевые куски, далее мелкий декор.
- `Water_01-04` - блоки воды, `Water_05-08` - камни+камыш, `Water_09-49` - брызги, круги, волны.
- `Fall_01-04` - кадры водопада для анимации.
- `Seabed_01-03`, `Underwater_01`, `WaterPlant_01-28`, `Lily_01-03`, `Reed_01-03`, `RiverRock_01-16`.

Нарезка сделана питоном (Unity-нарезчик на больших листах падал), размеры точные, пивот будет bottom-center.

## Правила
- Проходимая поверхность - только плоский верх камня/плиты; коллайдер = прямоугольник по этому верху.
- Силуэт - декор, по нему никто не ходит.
- Вода - блоки Water_01-04 + волна сверху; не тайлить листами по вертикали.
