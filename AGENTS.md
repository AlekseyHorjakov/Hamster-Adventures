# AGENTS.md — правила работы

## Бюджет токенов
- Работать максимально экономно: у проекта очень ограниченный бюджет.
- Не перечитывать большие файлы целиком; использовать точечный поиск по нужным фрагментам.
- Не повторять Unity batchmode, сборки и проверки без технической необходимости.
- Из логов читать только ошибки и последние строки.
- Объединять независимые проверки в один вызов инструмента.
- Держать промежуточные рассуждения и итоговые ответы короткими.
- Обновлять документацию кратко, без повторного пересказа уже известных фактов.
- Сначала исправлять конкретную проблему, не расширять задачу без запроса.
